# tezkor-yordam

Tezkor Yordam ilovasining landing sahifasi — Next.js + Tailwind CSS.

## Ishga tushirish

```bash
npm install
npm run dev
```

Brauzerda oching: http://localhost:3000

## Asosiy fayllar

- `src/app/page.tsx` — sahifadagi barcha bo‘limlar
- `src/app/layout.tsx` — SEO (meta teglar)
- `src/lib/site.ts` — domen, do‘kon havolalari, FAQ matnlari
